# Glossario

Una parola sola per ogni cosa, nelle due lingue dell'interfaccia. Vale per i testi di `src/lib/i18n`, per le due guide, per le novità e per il sito. Chi aggiunge o cambia un testo controlla qui la parola da usare; se serve un termine nuovo lo aggiunge a questa tabella nella stessa modifica.

| Italiano | English | Che cos'è | Da non usare |
| --- | --- | --- | --- |
| albero | tree | L'elenco di parti, capitoli e scene a sinistra del testo | indice, outline |
| indice | table of contents | Solo quello del libro esportato | |
| manoscritto | manuscript | La sezione con il testo del romanzo | |
| parte, capitolo, scena | part, chapter, scene | I tre livelli del manoscritto | |
| paragrafo | paragraph | Un capoverso; nei libri game anche la sezione numerata | |
| Bibbia | Story Bible | La sezione con personaggi, luoghi e il resto | Codex |
| scheda | card | Una nota della Bibbia | voce, entry, sheet |
| tipo | type | Il tipo di una scheda: personaggio, luogo, trama… | |
| trama | plotline | Il tipo di scheda che segue un filo della storia | Plotline in italiano |
| nota | note | Un file Markdown fuori dal manoscritto | |
| proprietà | property | Un dato di una scena o di una nota (stato, pov…) | campo, metadato |
| campo | field | Una colonna o un dato mostrato in una vista | |
| vista | view | Una tabella, lista, bacheca o linea del tempo salvata | |
